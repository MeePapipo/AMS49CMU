## ขึ้น Cloudflare Pages จาก repo นี้

Cloudflare Pages เชื่อมกับ GitHub ได้โดยตรง (Workers & Pages → Create → Pages → Connect to Git)
ตั้งค่าตอนสร้างโปรเจกต์ตามนี้

| ช่อง | ค่า |
|---|---|
| Framework preset | None |
| Build command | *(เว้นว่าง)* |
| Build output directory | `public` |
| **Root directory (advanced)** | **`app`** ← ต้องใส่ ไม่งั้น Pages จะมองหาไฟล์ที่ราก repo แล้วไม่เจอ |

หลัง deploy ครั้งแรกยังใช้งานไม่ได้ทันที ต้องสร้าง D1 / R2 และตั้งความลับก่อน —
ทำตาม [app/DEPLOY.md](app/DEPLOY.md) ตั้งแต่ข้อ 1

> อีกทางคือ deploy ตรงจากเครื่องด้วย `npm run deploy` ซึ่งไม่ต้องพึ่ง GitHub เลย
> วิธีนี้ `wrangler.toml` คุมทุกอย่างให้อยู่แล้ว จึงไม่ต้องตั้งค่าอะไรในหน้าเว็บ Cloudflare

## สิ่งที่ **ไม่ได้** อยู่ใน repo นี้ และห้ามเพิ่มเข้ามา

`.gitignore` ที่รากกันไว้แล้ว แต่เขียนไว้ตรงนี้ด้วยเพราะเป็นเรื่องที่พลาดแล้วแก้ยาก

- **`เลขบัญชีสำหรับบริจาคเงิน/`** — ภาพถ่ายสมุดบัญชี **มีลายเซ็นผู้มีอำนาจและตราประทับธนาคาร**
  ติดมาในภาพ นี่คือเหตุผลที่เว็บแสดงเลขบัญชีเป็นข้อความเท่านั้น ไม่เคยเอาภาพขึ้น
  ถ้า push ขึ้น repo สาธารณะแล้ว ลบ commit ทีหลังไม่พอ ต้องเขียนประวัติใหม่ทั้งเส้น
  และของอาจถูกดึงไปแล้ว
- **`app/.dev.vars`** — รหัสผ่านแอดมินตอน dev และคีย์เซ็น session
  ความลับของจริงอยู่ที่ `wrangler pages secret put` ไม่เคยอยู่ในไฟล์
- `Logo/` `Shirt Picture/` `Size/` — ไฟล์ต้นฉบับความละเอียดสูง ไม่เป็นความลับแต่ไม่ต้องใช้
  ภาพที่เว็บใช้จริงถูกย่อไว้ใน `app/public/assets/img/` แล้ว

## หมายเหตุเรื่อง `prototype/`

ทำไมค้นด้วยชื่อไม่ได้ ทำไมไม่โชว์ที่อยู่เต็ม) ซึ่งยังใช้อ้างอิงอยู่
